HOW IT WORKS

1. Add your masters (files or folders; drag rows to set the track order) and give each a title and ISRC.

2. Fill in the metadata once: it goes into every file in the format's own tags (WAV: INFO list and an ID3 chunk; AIFF: ID3; FLAC: Vorbis comments; MP3: ID3v2.3 + v1; AAC: iTunes tags), with the artwork.

3. Add one OUTPUT row per version you deliver. Each source is made in each version, into its folder; folder and file names can use tokens like {track:02}, {title}, {bits}, {khz}, {format}.

Quality. Sample rates are converted with the SoX resampler at its very-high-quality setting (28-bit, linear phase, flat to the top of the band) in 64-bit float. 16-bit results get TPDF dither (or noise-shaped at 44.1 / 48 kHz); 24-bit and float are not dithered. MP3 is LAME at its best quality, AAC Apple's encoder on a Mac. Every file is read back and checked (rate, word length, channels, length, peak); anything that reaches full scale is flagged.

Keys. Ctrl/Cmd+Enter converts · Delete removes the selected source.
