# …pump

Mastering plugins and creative effects by **wake**, in the look of Thunder Plus's *Simple* skins: flat and square, ink outlines with an
offset block, Share Tech Mono, one light-neon colour per plugin, light or dark. VST3 and CLAP on Windows and macOS
(plus Audio Units on macOS), built for Ableton Live and any other host.

| **pump COMP** Compressor | pink | Clean, Glue, Opto, Punch, Vari-Mu and Pump styles; lookahead; external sidechain with sidechain EQ; stereo link and mid/side |

## Download

The newest builds are always on the [latest release](https://github.com/matthettich/pump/releases/tag/latest):
`pump-macos.pkg` (installer, Apple Silicon + Intel), `pump-macos.zip`, `pump-windows.zip`. Each zip has an
`INSTALL.txt`. On Windows, `Install pump.bat` in the zip installs everything; both installers first move any pump
plugins already installed (old, renamed or removed ones) to a `pump-previous` backup, so nothing is left twice, and
each has an uninstaller (`Uninstall pump.bat`, `Uninstall pump.command`).

## System EQ (Mac)

**System EQ** puts pump EQ on everything your Mac plays (macOS 14.2 or later). It's a menu-bar app with the full EQ
window; `pump-macos.pkg` installs it in Applications, and `system-eq-macos.zip` has the app on its own.

- It follows the Mac's own output and sample rate: pick speakers or headphones as usual and it moves with you.
- **Separate EQ for each output** (menu, on by default): every output keeps its own settings; a new one starts from
  the latest settings. Turn it off to use one EQ everywhere.
- Only audio going to the current output is processed: an app playing to another device (a DAW on an audio
  interface) is left alone.
- During silence it skips the EQ, and with nothing playing it stops the audio device; it starts again the moment an
  app plays.
- **EQ On** in the menu turns it off and gives the Mac its untouched output back. *Open at Login* starts it with the Mac.
- The first start asks for permission to record system audio (that's how it hears other apps). If you hear nothing,
  *Audio Recording Permission…* in the menu opens the right page in System Settings. Unsigned builds may ask again
  after an update.
- Linear phase adds latency to everything, video included: zero latency suits everyday listening.

## pump ROOM (room measurement, Mac and Windows)

**pump ROOM** measures your speakers in your room with any measurement microphone. It's one page,
`pump-room.html` on the [latest release](https://github.com/matthettich/pump/releases/tag/latest): open it in Chrome
or Edge, nothing to install. This is the first stage of room correction; turning measurements into a correction
(pump ROOM as a plugin, in System EQ, and on Windows as settings for a free system-wide equalizer) comes next. See
[docs/ROOM.md](docs/ROOM.md).

- **START AUDIO**, pick the mic (and its input, on an interface) and the output. Allow the microphone when asked.
- **Mic calibration:** load the mic's calibration file (frequency / dB per line: the usual .txt, .cal or .frd files
  read as they are). Without one the mic is taken as flat.
- **TEST LEVEL** plays pink noise: set the volume so the mic meter sits in the shaded band (-30 to -12 dBFS).
- **MEASURE** plays a sweep from each speaker in turn and shows the response (smoothing, window, normalize), the
  impulse view, and for both speakers how much later one arrives (and by how much to delay the other) and the level
  difference between them.
- Turn System EQ (and any other correction) off while measuring. **SAVE** keeps the measurements for later;
  **TXT** and **WAV** export a response or an impulse response for other tools.

## Using them

Every plugin shares the same mouse and key conventions. Press **?** in a plugin for its full list.

In your host they sit in three folders (the vendor): **wake mastering**, **wake effects** and **wake instruments**; hosts that sort by category (Bitwig, Reaper, Studio One) also see EQ, Dynamics, Reverb, Synth, Drum and so on.

- drag a control (Shift = fine), mouse wheel steps it, double-click or Ctrl-click (Cmd-click on a Mac) resets it; on a Mac,
  Ctrl-click is a right-click, as everywhere else in macOS
- right-click to type a value (in hosts that pass the keyboard to plugins): `1k`, `A4`, `C#3+13`, `2x` (= +6 dB), `50%` (halfway); Tab = next field
- Ctrl/Cmd+Z undo, Shift+Ctrl/Cmd+Z or Ctrl+Y redo; A/B compare with COPY; factory presets with ◀ ▶
- hold **Alt** on a band to solo it while held (EQ nodes, multiband regions); drag while soloed to move it (up = narrower,
  down = wider). On empty spectrum space, Alt-hold listens to the range under the mouse (drag to sweep; up/down or wheel = width)
- DARK switches the look and is remembered for new instances
- EQ dynamic bands: select a band, turn on DYNAMIC, set RANGE and THRESH; Alt+double-click on the
  curve makes a dynamic band directly
- COMP has a stereo sidechain input: set SC to External and route a track to the plugin's sidechain in your host
- VOX goes on your vocal: its built-in synth sings along (FOLLOW) or plays the MIDI you send it (in Live: a MIDI track's
  *MIDI To* set to the vocal track, VOX). For your own synth as the carrier, set ROUTE to *Sidechain carrier* and send
  the synth to VOX's sidechain; *Split L/R* takes one stereo track with the carrier left and the voice right
- STUTTER: hold a pad (or keys 1-8) to play a move; MIDI notes C, C#, D, D#, E, F, F#, G of any octave do the same (in
  Live: a MIDI track's *MIDI To* set to the track with STUTTER). The small AUTO box on a pad lets the dice pick that move
- AMP: LOAD a `.nam` model (the free captures people share) and a cabinet `.wav`; `<` `>` step through the other files in
  the same folder. The paths are saved with the session
- The instruments take MIDI from the host (in Live, put them on a MIDI track); the keyboard at the bottom of their window
  plays too. TABLE: drag a table screen up / down to move its position, the wheel changes the table; LOAD reads a .wav
  wavetable (frames of 2048 samples) into USER
- KIT, STRIKE, BOING and MACHINE play their pads in order a whole step apart from C4 (C4 D4 E4 F#4 ...; each pad shows
  its note), and still answer the General MIDI drum notes (36 kick, 38 snare, 42 / 46 hats, toms 41-50, cymbals 49-59);
  MACHINE also plays its seven sounds chromatically on MIDI channels 2-8. Click a pad (or keys 1-8 / 1-7) to play it and
  edit it. MACHINE's LOAD KIT reads a kit file (.snd) from the machine's card
- SING: click the lyrics (or EDIT), type or paste, Enter. Every note sings the next syllable; a comma or full stop is a
  rest, `~` holds the last vowel over another note, `hel-lo` splits a word where you like, `[HH AX L OW]` spells the
  sounds. The lyrics start over when the host starts playing (or with RESTART) and are saved with the session
- SING voicebanks: LOAD BANK and pick the bank's oto.ini; ENGINE switches to VOICEBANK. Lyrics in romaji ("ka ki
  ku") find a Japanese bank's syllables directly; English words are matched by their sounds
- PHASE: pick an ENGINE, then click the ALGORITHM screen's halves (or scroll) to step through its algorithms; click an
  operator (or keys 1-6) to edit it. A carrier's LEVEL is its loudness, a modulator's is the FM depth. CHIP off plays
  the same voice clean
- PRISM: LOAD A (or pick a built-in SOURCE) and play. Drag on the SOUND picture to set START / END (or SCAN when
  frozen); FORMANT 100 keeps a voice a voice when you play it far from its own pitch; MORPH needs a SOURCE B
- MODAL: pick an OBJECT and an EXCITER and play. Drag on the OBJECT picture to move where it is struck; MATERIAL is
  the big one (wood, glass, metal); BOW and BREATH sound for as long as you hold the key
- ORBIT: CHAOS and SYNC are the two to learn. Low CHAOS and high SYNC is a clean, pitched tone; raise CHAOS for period
  doubling (sub-octaves) and then noise; lower SYNC to let it wander. AXIS changes the timbre without changing the orbit
- FOLD: for the classic ping, STRIKE with a short RISE and FALL and let RESPONSE make the ring; FOLD and SYMMETRY are
  the timbre, MOD>FOLD and FM make it move; CYCLE turns the function into a rhythm while you hold a key
- VECTOR: drag the joystick on the square to mix the four sources; turn ENV up and drag the numbered path points to make
  the mix move by itself. Set a source to SEQ to step through the bank from its wave, or SCAN for a struck, moving string
- FREEZE: pick a SOURCE (or LOAD a .wav) and drag on its picture to choose the moment; SPEED 0 holds it frozen. PHASE
  0 is the classic wash, higher is steadier and more tonal; GRAINS, SPRAY and BLUR make it a cloud
- TRACT: click a vowel (or drag between them) and play; SIZE makes it a child or a giant, SINGERS a choir. TENSE and
  BREATH go from a pressed voice to a whisper
- CHOP: play your track through it and hold a pad (mouse, keys 1-8, MIDI C3 up, or map Pad 1-8 Trigger to any key in your DAW): it plays that slice of the bar
  just gone. Hold two to loop between them; LEARN on a pad, then a note or a key, maps it
- BOING: click a pad (or 1-8) to play and edit it; BLEND goes from the analog voice (0) to the spring (100). The kick
  and toms get their thump from BEND (the analog layer's pitch drop) and their boing from the spring
- STRIKE: click a pad (or 1-8) to play and edit it; pick its ENGINE and the three middle dials change their names to what
  they do there. The kits show each engine off: Physical, Analog circuits, FM, West coast, Chaos
- LIFE: press play in the host (LOOP and EVOLVE follow the song; FREE runs on its own). Draw on the grid, pick a
  PATTERN, or RANDOM; the cell colours are the voices (X-WRAP, Y-WRAP and COLOUR change which); SENSITIVITY sets how few
  cells it takes to play one. Drag across the TONES bars to shape the kit
- COIL plays like any synth; KICK (or K) kicks every ringing spring again. To modulate, drag a source's grip (MODULATION,
  bottom right) onto any dial; MOD shows the source's settings and every connection (drag an amount, x removes). TWANG goes on a track or a send: CHORD tunes
  the springs to ROOT + CHORD + OCTAVE, MIDI to the notes you hold (send it MIDI, or play its keyboard), LATCH to the
  last chord until you play a new one. HARMONIC 0 is the springs as they are; 100 is in tune with itself
- TUNE goes on a solo voice. Live: set KEY and SCALE (or send it MIDI notes) and RETUNE. Graph: turn CAPTURE on and play
  the song once; the voice appears as notes on the host's timeline: drag them (Alt = free), double-click to snap,
  select several to STRAIGHTEN, change VIBRATO, FORMANT or GAIN. The edits are saved with the session

## Presets

Every plugin's preset menu has three groups of factory presets, plus your own:

- **Factory**: general starting points.
- **Sources**: for single tracks and buses (Vocals, Drums, Kick, Snare, Bass, Guitars, Keys, Synths, Pads, Bus). They
  are set for sources peaking around -6 dBFS; move THRESH or GAIN by the same amount for quieter or hotter tracks.
- **Chains** (mastering plugins): seven matching mastering chains (Pop, EDM, Hip-hop, Rock, Acoustic & jazz, Lo-fi, Streaming -14). Load
  the same name in each plugin, in this order: EQ, CALM, COMP, BAND, HEAT, TONE, WIDE, LIMIT, METER. On dense mixes,
  lower LIMIT's GAIN by 1-3 dB to land on the target loudness.
- **Your presets**: *Save preset…* at the end of the menu. They're stored as small text files (one folder per plugin)
  in `Documents/wake/pump/Presets/` on macOS and Windows, `~/.local/share/wake/pump/Presets/` on Linux, and show up in
  every session and every copy of the plugin.

## Building

```
git clone --recursive https://github.com/matthettich/pump   # (AMP needs the NAM core's Eigen submodule too)
make            # all plugins into bin/  (Windows: cross-compile with MinGW, see .github/workflows/build.yml)
make tests      # offline DSP tests
```

See [docs/DEVELOPING.md](docs/DEVELOPING.md) for the framework, the shared DSP library and how to add a plugin. The DSP
in `common/dsp` and each plugin's `*Engine.hpp` has no framework code, so it also compiles to WebAssembly: `make wasm`
builds `pump.wasm` for Thunder Plus, where the nine run as bus and master effects (`wasm/`).

Developer pick-up notes (state, verified vs unverified, open issues): [docs/HANDOVER.md](docs/HANDOVER.md).
