…pump plugins — Windows install
===============================

EASIEST: double-click "Install pump.bat" (in this folder, after unzipping)
  Windows asks for administrator rights once (the plug-in folders need them). Close your host (Ableton Live,
  Renoise...) first: it can't replace a plugin that's open, and says so if one is. It then
    - moves every pump plugin already installed (old versions, renamed or removed ones, copies in your user
      plug-in folders) into C:\Program Files\Common Files\pump-previous - only the last version is kept there,
      and hosts don't look in it; copy it back to undo
    - copies these plugins into C:\Program Files\Common Files\VST3\ (and the CLAP ones into ...\CLAP\)
    - says what was updated, what's new and what was taken out.
  "Uninstall pump.bat" removes every pump plugin (and the backup).
  If Windows says it protected your PC (SmartScreen): More info > Run anyway.

OR: copy the files yourself
1. Copy every pump-….vst3 folder (pump-eq.vst3, pump-comp.vst3, …) into:
       C:\Program Files\Common Files\VST3\
   (Windows asks for permission once; that folder is where Ableton Live and other hosts look.)

2. Optional, for hosts that use CLAP (Bitwig, Reaper): copy the files in the CLAP folder into:
       C:\Program Files\Common Files\CLAP\

3. In Ableton Live: Options > Preferences > Plug-Ins, turn on "Use VST3 Plug-In System Folders",
   then press Rescan. The plugins appear under Plug-Ins in three folders: wake mastering, wake effects
   and wake instruments.

Mastering: pump EQ, pump COMP, pump LIMIT, pump CALM, pump TONE, pump BAND, pump WIDE, pump HEAT, pump METER.
Effects:   pump TUBE, pump SNAP, pump GATE, pump ECHO, pump SPRING, pump VERB, pump GRAIN, pump VOX, pump TUNE, pump CRUSH, pump SWIRL, pump STUTTER, pump CHOP, pump AMP, pump TWANG.
Instruments: pump TABLE, pump MONO, pump POLY, pump WOB, pump KIT, pump SING, pump COIL, pump PHASE, pump LIFE, pump BOING, pump PRISM, pump MODAL, pump ORBIT, pump FOLD, pump VECTOR, pump STRIKE, pump FREEZE, pump TRACT, pump MACHINE (GPL-3.0: pump-MACHINE-NOTICE.md).
In every plugin: drag to change a control (Shift = fine), right-click to type a value, double-click or
Ctrl-click to reset it. A/B compares two settings; DARK switches the look (remembered for new instances).
