System EQ — Mac install (Apple Silicon and Intel, macOS 14.2 or later)
======================================================================

System EQ puts pump EQ on everything your Mac plays. (pump-macos.pkg installs it too.)

  1. Drag "System EQ.app" into Applications.
  2. Remove the quarantine flag once, in Terminal (the app isn't notarized by Apple yet):
       xattr -dr com.apple.quarantine "/Applications/System EQ.app"
     Or open it, click Done, then System Settings > Privacy & Security > Open Anyway.
  3. Open it. It has no Dock icon or window at first: look for the three-sliders icon in the menu bar,
     top right. Its menu opens the EQ window and has EQ On, Separate EQ for each output, Open at Login.
  4. The first start asks for permission to record system audio (that's how it hears other apps).
     If you hear nothing, choose Audio Recording Permission… in its menu.
